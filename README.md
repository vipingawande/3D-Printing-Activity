# FDM Print Quality Learning App

## What's included
- Student name and roll number.
- Section 1: interactive FDM parameter controls.
- Section 2: effects and guidance for current settings.
- Section 3: five individualized parameter-range comparison tasks selected from a task bank; students adjust values in Section 1 and write conclusions based on Section 2.
- Section 4: 15 MCQs, selected for each student based on name and roll number.
- PDF report with student details, selected settings, assigned tasks, conclusions, MCQ answers, score and answer explanations.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

The individualized assignment is a learning feature, not a secure examination/proctoring system. The same name and roll number produce the same assigned tasks and MCQs.
